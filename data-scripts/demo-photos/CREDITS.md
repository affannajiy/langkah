# Demo report photos

Example photos for the demo reports added by `seed_demo.py`. They come from
Wikimedia Commons and were **not taken at the Ipoh pins**: each demo report note
says where the photo is really from. Each file was resized to 1280 px wide JPEG
at 70% quality (guide Section 7.4), with the photo's metadata removed. No other
changes.
